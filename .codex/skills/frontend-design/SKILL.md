# Frontend Design

This skill guides the creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Use it when the user wants a component, page, poster, landing page, dashboard, application UI, or a stronger visual treatment for an existing web interface.

Implement real working code with exceptional attention to aesthetic details and creative choices. The output should be functional, visually striking, cohesive, and ready to live in a real product.

## When To Use This Skill

Use this skill when the request involves:

- Building a new frontend surface such as a page, section, component, app shell, or dashboard
- Styling or beautifying an existing UI that feels generic, weak, unfinished, or overly utilitarian
- Creating web-based artifacts with strong visual direction, including posters, promo sections, showcases, or microsites
- Translating product goals, audience, and brand tone into a concrete interface with real code

## Workflow

Before coding, understand the context and commit to a bold aesthetic direction. Do not jump straight into implementation with a default layout.

### 1. Understand the brief

Identify:

- **Purpose**: What problem does the interface solve, and what action should it support?
- **Audience**: Who uses it, and what should they feel when they encounter it?
- **Constraints**: Framework, responsiveness, accessibility, performance, design-system boundaries, and delivery expectations
- **Differentiation**: What is the memorable idea, visual gesture, or compositional move that makes the result unforgettable?

### 2. Choose a clear aesthetic direction

Pick a strong point of view and execute it with precision. Either bold maximalism or refined minimalism can work. The important thing is intentionality.

Possible directions include:

- Brutally minimal
- Maximalist chaos
- Retro-futuristic
- Organic and natural
- Luxury and refined
- Playful and toy-like
- Editorial and magazine-inspired
- Brutalist and raw
- Art deco and geometric
- Soft and pastel
- Industrial and utilitarian

These are starting points, not templates. Commit to one direction that feels true to the context rather than blending everything into a safe average.

### 3. Implement the vision in real code

Once the direction is set, build working HTML/CSS/JS, React, Vue, or the stack already used by the project.

The result must be:

- Production-grade and functional
- Visually striking and memorable
- Cohesive, with a clear aesthetic point of view
- Meticulously refined in spacing, typography, hierarchy, color, motion, and states

## Frontend Aesthetics Guidelines

Focus on the following design levers and use them deliberately.

### Typography

- Choose fonts that are beautiful, distinctive, and contextually appropriate
- Avoid generic choices such as Arial, Inter, Roboto, and default system-font solutions unless the existing product already requires them
- Prefer pairings with contrast, such as a characterful display face plus a refined body face
- Use typography to create identity, not just readability

### Color and theme

- Commit to a cohesive visual world instead of distributing many colors evenly
- Use CSS variables or theme tokens for consistency
- Favor dominant colors with sharp accent decisions over timid palettes
- Pick light or dark mode based on the concept, not habit

### Motion

- Use animation to create impact, pacing, and delight
- Prefer CSS-first motion for HTML implementations
- In React projects, use Motion when available and appropriate
- Prioritize high-value moments such as orchestrated page-load reveals, staggered entrances, scroll-triggered transitions, and meaningful hover states
- Use restraint where needed; one great sequence is better than many random micro-interactions

### Spatial composition

- Use asymmetry, overlap, diagonal flow, interruption, or grid-breaking placement where the concept benefits from it
- Balance density and negative space intentionally
- Avoid default section stacks and predictable card grids unless the product constraints truly demand them

### Backgrounds and detail

- Build atmosphere with layered gradients, patterns, textures, transparencies, grain, decorative borders, dramatic shadows, or geometric forms
- Backgrounds should support the concept rather than defaulting to flat fills
- Add details that feel designed for the context, not copied from generic UI kits

## Creative Standards

Interpret the brief creatively and make unexpected choices that feel genuinely designed for the use case. No design should be the same across requests.

Vary across generations:

- Light and dark themes
- Font families and pairings
- Composition strategies
- Interaction language
- Decorative systems and visual motifs

Do not converge on the same familiar answers across tasks.

## Never Do This

Never fall back to generic AI-generated aesthetics such as:

- Overused font families, including Inter, Roboto, Arial, or default system stacks without a strong reason
- Predictable purple gradients on white backgrounds
- Cookie-cutter hero sections, dashboard cards, or interchangeable landing-page layouts
- Generic component patterns with no context-specific character
- Safe, averaged design decisions that flatten the concept

## Implementation Notes

- Match implementation complexity to the aesthetic direction
- Maximalist concepts may require richer layering, stronger visuals, and more elaborate motion systems
- Minimalist concepts still require rigor through spacing, proportion, type choices, restraint, and surface detail
- Preserve the established design system when working inside an existing product, but still look for ways to elevate the result within those constraints
- Ensure the final UI works across desktop and mobile unless the request explicitly targets a single form factor

## Success Criteria

The finished result should:

- Solve the product need with real, usable frontend code
- Feel distinctive rather than template-driven
- Express a strong and coherent aesthetic direction
- Avoid generic AI styling cues
- Hold up in production-quality scrutiny

Remember: extraordinary creative work comes from making intentional choices and carrying them through every detail.
